# RNA-Seq Concepts

## What is RNA-seq?

RNA sequencing, or **RNA-seq**, is a high-throughput sequencing method used to characterize RNA molecules present in a biological sample.

RNA-seq allows researchers to examine the transcriptome, which represents the collection of RNA transcripts produced by cells under a particular biological condition.

In this study, RNA-seq was used to investigate how the transcriptional profile of elephant seal endothelial cells changes following exposure to hypoxia.

---

## Why Use RNA-seq for a Hypoxia Study?

Hypoxia can alter the transcription of genes involved in cellular metabolism, oxygen sensing, oxidative stress, angiogenesis, and other physiological processes.

RNA-seq allows researchers to examine many genes simultaneously and identify transcriptional differences between control and hypoxia-exposed cells.

This provides a molecular perspective on how elephant seal cells respond and adapt to reduced oxygen availability.

---

## What is a Biological Replicate?

A **biological replicate** is an independent biological sample representing the same experimental condition.

Biological replicates are important because living systems naturally exhibit biological variation.

Using multiple biological replicates allows researchers to determine whether an observed transcriptional response is reproducible across independent samples.

# Genomic DNA vs. RNA

Genomic DNA contains the relatively stable hereditary information of an organism.

RNA, in contrast, reflects genes that are being transcribed under particular cellular and environmental conditions.

Therefore:

**Genome**
→ indicates which genes are present

**Transcriptome**
→ indicates which genes are being expressed

RNA-seq is particularly useful for studying hypoxia because the transcriptional response of cells can change when oxygen availability decreases.
